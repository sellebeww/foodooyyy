# Demo scenarios

Generated by `npm run seed` from `src/demo/`. Do not edit by hand.

**All four stalls are synthetic demo data.** They are labelled "Demo data" in the app. The "true mean" is the generator's hidden demand; it is never stored in the app.

In the app, **Launch Demo App** (company page) opens a chooser with all four stalls, a 7-step tutorial, a guided case per stall and the four moments, and **Try demo stall** (Start page) and **Settings → Choose another demo stall** offer all four, as does the **Demo data** badge inside the app. A moment button opens one stall directly at the morning plan, selling, closing time or weekly summary, using a simulated demo time; **Open with the real clock** skips that. Each history always ends the day before the stall day it is loaded or opened on: when the app is opened on a later day, the demo is generated again with the same scenario, so the content stays the same and only the dates move. `VITE_DEMO=off` in `.env` hides the demo; empty or `on` shows it (see `.env.example`).

The history below ends the day before 2026-12-01 (Tue). In the app the dates follow the current day, and because demand depends on the weekday, the numbers there differ slightly.
